⚙ SETUP — Google Sheets API Key

You need a free Google API key to pull live data. Takes ~2 minutes:

  1. Go to console.cloud.google.com and sign in
  2. Create or select a project (top-left dropdown)
  3. APIs & Services → Library → search Google Sheets API → Enable it
  4. APIs & Services → Credentials → + Create Credentials → API Key
  5. In the API restrictions dropdown, select Google Sheets API, then click Create
  6. Copy the key (starts with AIzaSy…) and paste below
