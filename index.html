⚙ SETUP — Google Sheets API Key

The site uses the Google Sheets API v4. You need a free API key — takes ~2 minutes:

  1. Go to console.cloud.google.com and sign in
  2. Create a project (top-left dropdown → New Project)
  3. APIs & Services → Library → search Google Sheets API → Enable
  4. APIs & Services → Credentials → + Create Credentials → API Key
  5. Copy the key and paste it below
